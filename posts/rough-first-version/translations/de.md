Sie schreiben einen ersten Satz, löschen ihn, schreiben ihn neu, löschen ihn wieder, und plötzlich ist eine Stunde vergangen. Wer von Anfang an gut schreiben will, bekommt das Urteil vor dem Text. Die Aufgabe einer ersten Fassung ist nicht, gut zu sein, sondern bis zum Ende zu existieren. Ein grober Text, der das Ende erreicht, lässt sich verbessern. Ein auf halbem Weg aufgegebener Text hat nichts, was man verbessern könnte.

## Warum eine grobe erste Fassung hilft

Schreiben und Auswählen sind zwei verschiedene Arbeiten, und beides gleichzeitig zu tun verlangsamt beides. Lassen Sie beim Schreiben stehen, was kommt, und verschieben Sie das Auswählen auf später. Dann halten Sie einen fertigen Text in der Hand, und erst dann sieht man, was sich ändern muss.

## Drei Schritte für eine grobe erste Fassung

1. **Setzen Sie ein kleines Ziel.** Wählen Sie ein Ende, das Sie sehen können, etwa „fünf Sätze“ oder „zehn Minuten“. Wenn das Ende sichtbar ist, schwindet die Lust, auf halbem Weg aufzugeben.
2. **Gehen Sie weiter, ohne zurückzublicken.** Wenn ein Wort nicht kommt, lassen Sie eine Lücke, [ ], und schreiben Sie weiter. Wegen eines Wortes anzuhalten reißt den Faden. Löschen Sie nicht; lassen Sie Fehler, wo sie sind.
3. **Halten Sie am Ziel an und schließen Sie, ohne zu lesen.** Nehmen Sie zuerst an, dass Sie am Ende angekommen sind. Das Wiederlesen kann warten, sogar bis morgen.

## Beispiel: Ein Dank an die Nachbarin

Nehmen wir an, Sie schreiben der Nachbarin eine Dankesnachricht. Eine grobe erste Fassung sieht so aus:

> Letzte Woche, vielen Dank, dass Sie [ ]. Ehrlich gesagt war es ein schwerer Tag, aber als ich das [ ] vor meiner Tür sah, musste ich lächeln. Ich weiß nicht, was ich sagen soll, aber jedenfalls wollte ich Danke sagen.

Es gibt Lücken und holprige Stellen. Trotzdem steht alles darin, was Sie sagen wollten. Später füllen Sie die [ ] und glätten das „jedenfalls“. Hätten Sie von Anfang an nach dem perfekten Dank gesucht, hätten Sie vielleicht noch keine Zeile geschrieben.

## Damit Ihnen Grobes nicht peinlich ist

Eine erste Fassung ist nichts zum Herzeigen. Betrachten Sie sie als Ihre Arbeitskopie, dann wird der Kopf leichter. Behandeln Sie sie wie einen Zettel in der Schublade. Dass sie grob wirkt, ist kein Zeichen, dass der Text falsch ist; es heißt nur, dass Sie ihn noch nicht überarbeitet haben.

## Häufige Stolpersteine

- **Am ersten Satz hängen bleiben.** Der erste Satz ändert sich oft beim Schreiben. Setzen Sie einen vorläufigen und gehen Sie weiter.
- **Beim Schreiben korrigieren.** Eine Zeile schreiben und eine Zeile löschen führt nirgendwohin. Das Korrigieren kommt, nachdem Sie bis zum Ende geschrieben haben.
- **Sich mit anderen Texten vergleichen.** Legen Sie den fertigen Text eines anderen neben Ihre erste Fassung, und Sie verlieren immer. Mit einem fertigen Text vergleicht man Ihre zweite Fassung.

## Tipps für die Arbeit mit draft()

Wenn Sie etwa dreißig Sekunden sprechen, kommt das Gesagte von selbst grob heraus. Es muss nicht flüssig sein. Beantworten Sie die zwei oder drei sanften Fragen von draft() und sammeln Sie so eine grobe erste Fassung. Das Glätten kommt danach.

## Probieren Sie es heute

Wählen Sie einen kurzen Text, den Sie heute schreiben möchten. Setzen Sie das Ziel auf „fünf Sätze“, lassen Sie dort ein [ ], wo Sie stecken bleiben, und schreiben Sie bis zum Ende. Lesen Sie danach nicht noch einmal durch; schließen Sie einfach.
